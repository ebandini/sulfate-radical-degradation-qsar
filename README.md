# Sulfate radical degradation of micropollutants

Code and analysis outputs for the QSAR modelling reported in:

> Bandini E, Liu Z, Katsaounis A, Lynen F, Kajtazi A. *Sulfate radical-based degradation of micropollutants in water: assessment of the relative degradation speed of monocyclic aromatic and aliphatic compound groups.*

The accompanying manuscript and supporting-information documents are not part of this code repository.

## Analysis scripts

- `qsar_benchmark.py` runs the QSAR model comparison with nested cross-validation and generates the model comparison, parity, and leakage figures and result tables.
- `feature_selection.py` runs descriptor stability selection and the descriptor-count analysis.
- `final_results.csv`, `loo_predictions.csv`, `best_params.json`, `baseline_results.json`, and `feature_selection_results.json` are generated result files.
- `Fig_R1_ModelComparison.png` through `Fig_R6_FinalParity.png` are the figures regenerated by the scripts.

The other top-level PNGs were supplied with the project folder and are not regenerated by these scripts. The generated result table and figures were regenerated from `dataset.csv` with the checked-in code and environment. In this environment, Gradient Boosting gives LOO Q2 = 0.476, RMSE = 0.853 and MAE = 0.664; repeated-CV R2 = 0.059 +/- 0.607. The manuscript reports Q2 = 0.52, RMSE = 0.82, MAE = 0.65 and R2 = 0.08 +/- 0.56. The two-variable aromaticity/TPSA baseline gives Q2 = 0.389, RMSE = 0.921 and MAE = 0.698; the manuscript reports 0.39, 0.92 and 0.74. The output environment pins scikit-learn 1.6.1, while the reviewer-response document refers to version 1.7. Reconcile these differences against the intended analysis environment before publication.

The manuscript also reports 200 y-randomization permutations (Gradient Boosting Q2 = -0.42 +/- 0.28). That analysis is not implemented in the scripts yet, so this repository does not reproduce that result.

## Input data

Both scripts read the included `dataset.csv` from the working directory. It is semicolon-delimited and contains `SMILES`, `Name`, and `lnk` columns.

## Software

The checked-in `environment.yml` records the environment used to regenerate the current results. Create it with Conda:

```bash
conda env create -f environment.yml
conda activate sulfate-radical-degradation-qsar
```

Alternatively, install the packages with pip:

```bash
python -m pip install -r requirements.txt
```

RDKit installation is platform-dependent; use the official RDKit installation guidance if pip cannot install it for your system.

## Run

```bash
python qsar_benchmark.py
python feature_selection.py
```

The scripts write figures and tabular/JSON outputs into the current directory, including `baseline_results.json`. Record package versions and the exact input data used when reproducing a publication result.
